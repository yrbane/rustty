# Panneaux — plan d'implémentation (plan 6)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal :** les demandes de seb du 2026-10-09 (deuxième salve) : redéfinir facilement les raccourcis (un fichier de configuration à éditer), redimensionner les panneaux à la souris et voir leur contenu se réorganiser (reflow des lignes), `ctrl+tab` / `ctrl+shift+tab` pour changer d'onglet, et un zoom de police propre au panneau survolé, sans toucher aux autres panneaux ni à la barre d'onglets.

**Architecture :** le reflow est un module pur de `rustty-vt` appelé par `Term::resize` quand la largeur change sur l'écran principal ; le glisser des barres est une opération pure de `rustty-layout` (position en pixels → ratio de la division) ; le renderer sait dessiner par-dessus une image existante, ce qui permet une passe par taille de police ; le binaire garde une taille de police par terminal et un renderer par taille utilisée.

**Spec :** `docs/superpowers/specs/2026-10-08-rustty-design.md` (§3.1 Term, §3.2 layout, §3.3 raccourcis, §3.6 binaire, jalon v0.2 « rewrap au resize » avancé ici) et les demandes de seb.

## Décisions prises

- **Raccourcis** : le mécanisme existe déjà (`[keys]`, surcharge et `"none"`), mais seb n'a pas de fichier : `rustty --init-config` écrit l'exemple complet et commenté au chemin par défaut (jamais d'écrasement).
- **Redimensionner** : glisser une barre de split à la souris (curseur ↔ / ↕ au survol) en plus des raccourcis `ctrl+flèches` existants ; une barre invisible (`border = false`) reste saisissable sur 4 px.
- **Reflow** : sur l'écran principal seulement (les applications plein écran redessinent l'écran alternatif elles-mêmes), historique compris, curseur suivi, caractères larges jamais coupés.
- **Zoom par panneau** : le zoom (molette ou clavier) vise le panneau sous la souris, sinon le panneau focalisé ; `ctrl+0` remet ce panneau à la taille de la config ; la barre d'onglets et les bandeaux gardent la taille de la config. Un rechargement de config qui change `font.size` remet tous les panneaux à la nouvelle taille.
- **Installation** (`cargo install`) : fonctionne déjà depuis les sources (`cargo install --path crates/rustty` ou `cargo install --git https://github.com/yrbane/rustty rustty`, vérifié) ; le README le documente, suivi de `rustty --install-desktop`. Publication sur crates.io écartée : le nom `rustty` y est pris et les crates internes n'y sont pas.
- **Affichage d'images (`img`)** : plan 7.

## Global Constraints

Identiques au plan 5 : anglais / français, une responsabilité par fichier (≤ ~300 lignes), TDD, tâche N → `0.1.0-alpha.(81+N)` (le plan porte `0.1.0-alpha.81`), CHANGELOG daté du jour, fmt + clippy `-D warnings` + tests verts, `git add` ciblé, défauts de rendu inchangés.

## Review Focus

1. **Reflow aux limites** : largeur 1, ligne pleine exactement à la largeur, caractère large en dernière colonne, lignes vides, curseur au milieu d'une ligne repliée, historique plein : aucune perte de texte, aucune panique, curseur sur le même caractère. Tests tâche 3.
2. **Glisser une barre hors de la fenêtre ou au-delà des bornes** : le ratio reste dans [0,1 ; 0,9], aucun panneau de taille nulle. Test tâche 2 (`drag_is_clamped`).
3. **Zoom d'un panneau puis fermeture, split ou rechargement** : pas de renderer orphelin indéfiniment, le nouveau panneau d'un split prend la taille de son parent ? — non : la taille de la config (simple et prévisible). Tests tâche 5.
4. **`--init-config` quand le fichier existe déjà ou que le dossier n'est pas inscriptible** : refus clair, rien d'écrasé. Tests tâche 1.
5. **Raccourci `ctrl+tab` dans une application qui l'utilise** : déliable par `"ctrl+tab" = "none"`. Test tâche 1.

### Task 2 : `rustty-layout` — glisser une barre de split

**Files :** `crates/rustty-layout/src/{node.rs, tab_layout.rs}`.

**Interfaces :** `TabLayout::drag_divider(&mut self, id: SplitId, bounds: Rect, gap: u32, x: u32, y: u32) -> bool` : place la barre de la division `id` au point `(x, y)` (abscisse pour une division verticale, ordonnée pour une horizontale), ratio = (position − début de la division) / espace disponible, borné à [MIN_RATIO, MAX_RATIO] ; faux si l'id est inconnu ou si un panneau est zoomé. `TabLayout::split_axis(id) -> Option<Axis>`.

- [ ] Tests : `dragging_a_vertical_divider_moves_it` (division 802 px, gap 2, glisser à x = 200 → barre à x = 200), `dragging_a_nested_divider_uses_its_own_bounds`, `drag_is_clamped` (x = 0 et x = 10 000 → ratios 0,1 et 0,9), `unknown_id_or_zoom_refuses`, `split_axis_reports_the_axis`. — échec — implémentation (`Node::drag` récursif qui recalcule les bornes avec `split_rect`) — vert — commit `rustty-layout : glisser une barre de split (0.1.0-alpha.83)`.

### Task 3 : `rustty-vt` — reflow des lignes au changement de largeur

**Files :** create `crates/rustty-vt/src/reflow.rs` ; modify `term/reset.rs`, `scrollback.rs`, `lib.rs`.

**Interfaces :**
- `reflow::reflow(lines: Vec<Line>, cursor: Option<(usize, usize)>, cols: usize) -> (Vec<Line>, Option<(usize, usize)>)` : `lines` de la plus ancienne à la plus récente, `cursor` = (ligne, colonne) dans `lines`. Les lignes physiques sont regroupées en lignes logiques (suite de lignes `wrapped`), les blancs de fin de chaque ligne logique sont retirés (sauf jusqu'au curseur), chaque ligne logique est redécoupée à `cols` colonnes (un caractère large qui ne tient pas en dernière colonne passe à la ligne suivante, la colonne laissée vide), `wrapped` posé sur toutes les lignes d'une ligne logique sauf la dernière ; le curseur est reporté sur le même caractère.
- `Term::resize(cols, rows)` : si `cols` change et que l'écran principal est actif, l'historique et la grille principale (jusqu'à la dernière ligne non vide ou au curseur) passent par `reflow`, les `rows` dernières lignes deviennent la grille (le curseur reste visible), le reste retourne à l'historique (plafond respecté) ; l'écran alternatif est seulement tronqué ou complété comme aujourd'hui ; le chemin sans changement de largeur ne change pas.
- `Scrollback::drain_all(&mut self) -> Vec<Line>` (de la plus ancienne à la plus récente).

- [ ] Tests (`reflow.rs`) : `a_long_line_rewraps_narrower`, `wrapped_lines_join_when_wider`, `hard_line_breaks_are_kept`, `trailing_blanks_are_dropped`, `wide_char_never_splits`, `width_one_keeps_every_char`, `cursor_follows_its_character`, `empty_input_is_empty`. (`term/reset.rs`) : `resize_narrower_reflows_screen_and_history`, `resize_wider_unwraps`, `alt_screen_is_not_reflowed`, `cursor_stays_visible_after_reflow`, `rows_only_change_keeps_previous_behavior`. — échec — implémentation — vert — commit `rustty-vt : reflow des lignes au redimensionnement (0.1.0-alpha.84)`.

### Task 5 : Zoom de police par panneau

**Files :** create `crates/rustty/src/pane_fonts.rs` ; modify `window_state.rs`, `render.rs`, `input.rs`, `effects.rs`, `model.rs`, `geometry` (appels), `main.rs`.

**Interfaces :**
- `pane_fonts::PaneFonts { base: f32, sizes: HashMap<TermId, f32> }` : `new(base)`, `size_of(term) -> f32` (base par défaut), `apply(term, change) -> bool` (vrai si la taille change ; `Reset` retire l'entrée), `forget(term)`, `rebase(base)` (oublie tout), `sizes_in_use(&self, live: &[TermId]) -> BTreeSet<SizeKey>` ; `SizeKey(u32)` = taille × 10 arrondie (clé de cache).
- `OsWindow` : `pane_fonts: PaneFonts`, `renderers: HashMap<SizeKey, Renderer>` (créés à la demande, ceux qui ne servent plus sont libérés à chaque `relayout`) ; `metrics_of(term) -> CellMetrics` pour `grid_size`, `cell_at`, la sélection et le curseur ; la barre d'onglets et les bandeaux utilisent toujours le renderer de base.
- Rendu : le renderer de base efface, dessine les panneaux à sa taille, les barres, la barre d'onglets et le bandeau ; chaque autre taille dessine ses panneaux (et leur sélection) avec `render_onto`.
- `Effect::FontSize(change)` vise le panneau sous la souris, sinon le focalisé (`model` ne change pas : la cible est choisie dans `effects.rs` par une fonction pure `zoom_target(hovered, focused) -> Option<TermId>` de `pane_fonts.rs`).
- Fermeture d'un terminal → `forget` ; rechargement changeant `font.size` → `rebase`.

- [ ] Tests (`pane_fonts.rs`) : `unknown_panes_use_the_base`, `zoom_changes_only_the_target`, `reset_removes_the_override`, `bounds_apply_per_pane`, `rebase_forgets_every_override`, `sizes_in_use_lists_distinct_keys`, `zoom_target_prefers_the_hovered_pane`. — échec — implémentation (puis essai à l'écran : deux panneaux, zoom de l'un) — vert — commit `rustty : zoom de police par panneau (0.1.0-alpha.86)`.
